## Key Learnings

1. **Product titles matter** — Include product names in captions (not images) to help users navigate destination pages
2. **Lifestyle scenes work** — Amala Earth aesthetic resonates; clean images + styled backdrops beat white/sterile product shots
3. **Pinterest warmup required** — New accounts need 2-week manual posting before Blotato can post via API
4. **Craft positioning strong** — Fizzy Goblet's artisan narrative translates well to social discovery
