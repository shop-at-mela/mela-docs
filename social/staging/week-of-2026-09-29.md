4. **Education visual:** the guide's preferred HTML/CSS→PNG toolchain isn't set up in this cloud session (no render pipeline available), so this fell to the toolchain's documented second choice, a Blotato illustrative-stills template (single infographic image, not a multi-slide hook→payoff carousel).
